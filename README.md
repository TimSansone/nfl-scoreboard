# NFL Scoreboard & GameCenter

A responsive NFL scoreboard with daily scores, AFC/NFC division filters, all 32 team schedules, play-by-play, player and team statistics, scoring summaries, leaders, weather, venue information, broadcasts, and available matchup data.

The app is a static site that loads public game data in the browser. Live games and open GameCenter details refresh automatically.

Data availability varies by game and season. This is an independent fan project and is not affiliated with or endorsed by the NFL or ESPN.
